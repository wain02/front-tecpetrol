# front-tecpetrol

Aplicacion frontend para analisis de presion de pozos.

## Como correr el frontend

1. Entrar al directorio del frontend:

```bash
cd frontend
```

2. Instalar dependencias:

```bash
npm install
```

3. Levantar el servidor de desarrollo:

```bash
npm run dev
```

4. Abrir la aplicacion en:

```text
http://localhost:5173
```

## Build de produccion

Para generar el build final:

```bash
npm run build
```

Para previsualizar el build:

```bash
npm run preview
```
